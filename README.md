# Radha Krishna Divine Creations - Laddu Gopal Poshak

An e-commerce storefront for handcrafted Laddu Gopal poshaks, featuring real-time size guides, dynamic cart calculations, free shipping progress tracker, and UPI QR code checkout with WhatsApp order confirmation.

## Features

- 🛍️ **Interactive Catalog**: Filter by collection (Heavy Festival, Daily Wear, Cotton Summer) or idol size (0 to 6).
- 📐 **Integrated Size Chart**: Interactive popup guide matching deity height to dress diameter.
- 🛒 **Cart Drawer**: Automatic total updates, quantity adjustments, and add-on accessories (Mukut & Bansuri).
- 🚚 **Dynamic Shipping Bar**: Real-time progress towards free shipping.
- 💳 **UPI Payment & WhatsApp Confirmation**: Direct UPI QR code generator and 1-click WhatsApp order confirmation.

## Deploy to Vercel

### Option 1: Via GitHub (Recommended)

1. Push your latest commits to GitHub:
   ```bash
   git push origin master
   ```
2. Open [Vercel](https://vercel.com) and log in.
3. Click **"Add New..."** > **"Project"**.
4. Import your repository: `psycho-04/jai-shree-shyam-poshak`.
5. Keep Framework Preset as **"Other"** (Root Directory: `./`).
6. Click **"Deploy"**.

### Option 2: Via Vercel CLI

```bash
npm install -g vercel
vercel
```
